About PloraLLM

PloraLLM is an open-source large language model designed for point cloud understanding and generation. It takes point cloud data as input, identifies objects within the scene, and outputs their semantic labels along with spatial coordinates.

The Model

1. Architecture: Based on the Transformer and other state-of-the-art pre-training frameworks.

2. Features: Efficient 3D perception, object-level point cloud parsing, spatial reasoning.

3. Open-Source LiDAR-based Point Cloud Dataset: We provide a labeled point cloud dataset acquired via LiDAR scanning, complete with robust annotations for research purposes.
