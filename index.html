About PloraLLM

PloraLLM is an open-source natural language processing project that combines multiple modalities for both understanding and generation. It aims to offer robust language model support for various downstream tasks.

The Model

1. Architecture: Based on the Transformer and other state-of-the-art pre-training frameworks.

2. Features: Lightweight, customizable plugins, multilingual support.

3. Open-Source LiDAR-based Point Cloud Dataset: We provide a labeled point cloud dataset acquired via LiDAR scanning, complete with robust annotations for research purposes.

4. Applications: Q&A, chatbots, text generation, summarization, and more.
